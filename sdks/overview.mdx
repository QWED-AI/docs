QWED provides official SDKs for 4 languages.

## Available SDKs

| Language                       | Package                      | Status   |
| ------------------------------ | ---------------------------- | -------- |
| [Python](/sdks/python)         | `qwed`                       | ✅ Stable |
| [TypeScript](/sdks/typescript) | `@qwed-ai/sdk`               | ✅ Stable |
| [Go](/sdks/go)                 | `github.com/QWED-AI/qwed-verification/sdk-go/v8` | Tagged releases (`sdk-go/vX.Y.Z`) |
| [Rust](/sdks/rust)             | `qwed`                       | ✅ Stable |

## Quick install

```bash
# Python
pip install qwed

# TypeScript
npm install @qwed-ai/sdk

# Go
go get github.com/QWED-AI/qwed-verification/sdk-go/v8

# Rust
cargo add qwed
```

## Minimal example

<Tabs>
  <Tab title="Python">
    ```python
    from qwed_sdk import QWEDClient
    
    client = QWEDClient(api_key="qwed_...")
    result = client.verify("2+2=4")
    print(result.verified)  # True
    ```
  </Tab>
  <Tab title="TypeScript">
    ```typescript
    import { QWEDClient, isAdmitted } from '@qwed-ai/sdk';
    
    const client = new QWEDClient({ apiKey: 'qwed_...' });
    const result = await client.verifyMath('2+2=4');
    console.log(isAdmitted(result));  // true
    ```
  </Tab>
  <Tab title="Go">
    ```go
    client := qwed.NewClient("qwed_...")
    result, _ := client.VerifyMath(ctx, "2+2=4")
    fmt.Println(result.IsAdmitted())  // true
    ```
  </Tab>
  <Tab title="Rust">
    ```rust
    let client = QWEDClient::new("qwed_...");
    let result = client.verify_math("2+2=4").await?;
    println!("{}", result.is_admitted());  // true
    ```
  </Tab>
</Tabs>
