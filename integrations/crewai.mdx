## Installation

```bash
pip install qwed crewai
```

## Quick start

```python
from crewai import Task, Crew
from qwed_sdk.crewai import QWEDVerifiedAgent

# Create a verified agent
analyst = QWEDVerifiedAgent(
    role="Financial Analyst",
    goal="Perform accurate financial calculations",
    backstory="Expert in financial modeling",
)

# Use in CrewAI workflow
task = Task(
    description="Calculate compound interest for $10,000 at 5% for 10 years",
    agent=analyst.agent
)

crew = Crew(agents=[analyst.agent], tasks=[task])
result = crew.kickoff()
```

## QWEDVerificationTool

Give agents verification capabilities:

```python
from crewai import Agent
from qwed_sdk.crewai import QWEDVerificationTool

agent = Agent(
    role="Data Analyst",
    goal="Verify calculations",
    tools=[QWEDVerificationTool()]
)
```

## Specialized tools

```python
from qwed_sdk.crewai import QWEDMathTool, QWEDCodeTool, QWEDSQLTool

agent = Agent(
    role="Developer",
    goal="Write secure code",
    tools=[
        QWEDMathTool(),   # Math verification
        QWEDCodeTool(),   # Code security
        QWEDSQLTool(      # SQL validation
            schema_ddl="CREATE TABLE users (id INT, name TEXT)",
            dialect="sqlite",
        ),
    ]
)
```

`/verify/sql` checks a query against the tables it runs on, so `QWEDSQLTool` takes their `CREATE TABLE` statements as `schema_ddl`, and `dialect` (default `sqlite`). Without a schema, or with one that is only whitespace, the tool sends no request and answers `⚠️ UNVERIFIABLE: no schema was given, so QWED cannot verify the query. ...`.

The tools call a result incorrect or unsafe only when QWED decided it. An `UNVERIFIABLE` or `BLOCKED` result, such as input that doesn't parse, a timeout or a server the client could not reach, returns its status and the server's message, for example `⛔ BLOCKED: ...`. `QWEDCodeTool` lists up to three issues the server reports for unsafe code, and `QWEDSQLTool` gives the server's reason for an unsafe query. `QWEDVerificationTool` sends the query to `/verify/natural_language`, which doesn't admit a result while the LLM translation is unverified, so it reports what holds or fails for the translated expression. A tool answer starts with `✅` only when the server admitted the result.

## QWEDVerifiedAgent

Agent wrapper with automatic verification:

```python
from qwed_sdk.crewai import QWEDVerifiedAgent, VerificationConfig

analyst = QWEDVerifiedAgent(
    role="Analyst",
    goal="Accurate analysis",
    backstory="...",
    verification_config=VerificationConfig(
        enabled=True,
        verify_math=True,
        verify_code=True,
        verify_sql=True,
        auto_correct=False,
        log_results=True,
        sql_schema_ddl="CREATE TABLE users (id INT, name TEXT)",
        sql_dialect="sqlite",
    )
)

# Check verification summary
print(analyst.verification_summary())
# {"total_outputs": 5, "verified": 4, "failed": 1}
```

`QWEDVerifiedAgent` builds its SQL tool with `sql_schema_ddl` and `sql_dialect` (default `sqlite`). Without `sql_schema_ddl`, the agent's SQL checks are `UNVERIFIABLE`.

`verify_output()` starts every output as unverified. It sets `verified: True` only when the client's `is_verified` is `True`, which follows the server's admission:

| Case | `verified` | `status` |
| --- | --- | --- |
| The server admits the output | `True` | Server status, for example `VERIFIED` |
| The server does not admit the output | `False` | Server status, for example `UNVERIFIABLE` |
| `VerificationConfig(enabled=False)` | `False` | `SKIPPED` |
| The check raises an error | `False` | `ERROR` |

`verification_summary()` counts only outputs with `verified: True`.

<Warning>
Before v8.0.0 ([GHSA-83v6-6h23-pvp4](https://github.com/QWED-AI/qwed-verification/security/advisories/GHSA-83v6-6h23-pvp4)), `verify_output()` started from `verified: True` and kept it when the check raised or verification was disabled. Don't rely on `verified=True` or verification rates from earlier versions.
</Warning>

## QWEDVerifiedCrew

Verify entire crew outputs:

```python
from qwed_sdk.crewai import QWEDVerifiedCrew

crew = QWEDVerifiedCrew(
    agents=[analyst, writer],
    tasks=[task1, task2],
    verify_final_output=True,
)

result = crew.kickoff()
print(result.verified)  # True/False
print(result.overall_verification_rate)  # 0.95
```

## Task decorator

```python
from qwed_sdk.crewai import verified_task

@verified_task(verify_output=True)
def process_result(output):
    # Output is verified before this runs
    return output.upper()
```
