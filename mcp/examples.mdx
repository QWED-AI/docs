## Example 1: financial calculations

### Scenario

You're building an LLM-backed financial advisor. Users ask for compound interest calculations, and you need QWED to verify the LLM's math.

### Setup

```json
{
  "mcpServers": {
    "qwed-verification": {
      "command": "qwed-mcp",
      "env": {
        "QWED_MCP_TRUSTED_CODE_EXECUTION": "true"
      }
    }
  }
}
```

### Conversation

**User:** Calculate the future value of \$10,000 invested at 5% annual interest, compounded monthly, for 10 years.

**Claude's process:**

1. Calculate: FV = P(1 \+ r/n)^(nt) = 10000(1 \+ 0.05/12)^(12×10)
2. Call `execute_python_code` to verify:

```json
{
  "code": "from decimal import Decimal, ROUND_HALF_UP\n\nP = Decimal('10000')\nr = Decimal('0.05')\nn = Decimal('12')\nt = Decimal('10')\n\nFV = P * (1 + r/n) ** (n*t)\nFV = FV.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP)\nprint(f'Future value: ${FV}')"
}
```

**Result:**

```text
STDOUT:
Future value: $16470.09

Execution completed successfully.
```

**Claude's response:** The future value is **\$16,470.09** (verified using deterministic decimal arithmetic).

## Example 2: legal reasoning

### Scenario

An AI legal assistant needs to check that a conclusion follows from legal premises.

### Conversation

**User:** Under contract law: If both parties agree and consideration is exchanged, a contract is formed. Alice agreed and paid Bob. Is there a valid contract?

**Claude's process:**

1. Formalize the argument as propositions
2. Call `execute_python_code` with a script that looks for a truth assignment where the premises hold and the conclusion does not:

```json
{
  "code": "from itertools import product\n\ndef implies(a, b):\n    return (not a) or b\n\ncounterexamples = [\n    (agreed, consideration, contract)\n    for agreed, consideration, contract in product([False, True], repeat=3)\n    if implies(agreed and consideration, contract) and agreed and consideration\n    and not contract\n]\nprint('valid:', not counterexamples)"
}
```

**Result:**

```text
STDOUT:
valid: True

Execution completed successfully.
```

The check covers the formalized argument only. Whether the propositions capture the legal question is up to the person who reviews the script.

## Example 3: code that is refused

### Scenario

A script tries to reach the file system. The server refuses it before it runs.

### Conversation

**User:** Run this with `execute_python_code`:

```python
import os
print(os.listdir("."))
```

**Result:**

```text
BLOCKED: QWED blocked python execution: Module 'os' is not admitted (line 1) (verification_id=...)
```

From v0.3.0, code that imports a module outside the allowlist, calls a refused builtin such as `open`, `eval` or `getattr`, or reads a private attribute is refused the same way, with the reason. Imports of QWED SDK packages, such as `qwed_new` or `qwed_legal`, and of other third-party packages are refused too. See [What code is admitted](/mcp/tools#what-code-is-admitted).

## Example 4: loan EMI

### Scenario

A car dealer quotes a monthly instalment, and you want the assistant to check it.

### Conversation

**User:** A dealer claims: "₹10,00,000 loan at 9% annual interest for 5 years = EMI of ₹20,758". Check it.

**Claude's process:**

```json
{
  "code": "from decimal import Decimal, ROUND_HALF_UP\n\nP = Decimal('1000000')\nr = Decimal('0.09') / 12\nn = 60\nemi = P * r * (1 + r) ** n / ((1 + r) ** n - 1)\nemi = emi.quantize(Decimal('0.01'), rounding=ROUND_HALF_UP)\nprint(f'EMI: {emi}')"
}
```

**Result:**

```text
STDOUT:
EMI: 20758.36

Execution completed successfully.
```

**Claude's response:** The claim holds to the rupee: the EMI is ₹20,758.36.

## Example 5: background job

### Scenario

You need to run a script that may exceed the 30-second synchronous timeout. Use `background=true` to dispatch the job asynchronously, then poll for results with `verification_status`.

### Conversation

**User:** Sum 1/k² for k from 1 to 2,000,000 and compare it with π²/6.

**Claude's process:**

1. Call `execute_python_code` with `background=true`:

```json
{
  "code": "import math\n\ntotal = math.fsum(1 / (k * k) for k in range(1, 2_000_001))\nprint(f'sum = {total}')\nprint(f'pi^2/6 = {math.pi ** 2 / 6}')",
  "background": true
}
```

**Response:**

```text
Verification order is being placed for the request a1b2c3d4-e5f6-7890-abcd-ef1234567890. Check back using the 'verification_status' tool.
```

2. Poll for results using `verification_status`:

```json
{
  "name": "verification_status",
  "arguments": {
    "job_id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890"
  }
}
```

**Response:**

```text
Status: success

Result:
STDOUT:
sum = 1.6449335668483513
pi^2/6 = 1.6449340668482264

Execution completed successfully.
```

<Note>
  Background jobs suit any script that may exceed the 30-second synchronous timeout. They are bounded by `QWED_MCP_BACKGROUND_TIMEOUT` (default 120 seconds, at most 600). See [Execution limits](/mcp/tools#execution-limits).
</Note>

## Example 6: Python MCP client

### Python code

Start the server over stdio and call both tools from your own code with the MCP Python SDK. This example sets `QWED_MCP_TRUSTED_CODE_EXECUTION` for the server it starts.

```python
import asyncio

from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client

SCRIPT = """
from decimal import Decimal, ROUND_HALF_UP

principal = Decimal("10000")
rate = Decimal("0.075")
n, years = 4, 5
amount = principal * (1 + rate / n) ** (n * years)
print("amount:", amount.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP))
"""


def text(result) -> str:
    return "\n".join(part.text for part in result.content if hasattr(part, "text"))


async def main():
    server_params = StdioServerParameters(
        command="python",
        args=["-m", "qwed_mcp.server"],
        env={"QWED_MCP_TRUSTED_CODE_EXECUTION": "true"},
    )

    async with stdio_client(server_params) as (read, write):
        async with ClientSession(read, write) as session:
            await session.initialize()

            # Run a script and wait for its output
            result = await session.call_tool(
                "execute_python_code", arguments={"code": SCRIPT}
            )
            print(text(result))

            # Run the same script as a background job
            result = await session.call_tool(
                "execute_python_code",
                arguments={"code": SCRIPT, "background": True},
            )
            job_id = text(result).split("request ", 1)[1].split(".", 1)[0]
            for _ in range(20):
                await asyncio.sleep(0.5)
                status = text(await session.call_tool(
                    "verification_status", arguments={"job_id": job_id}
                ))
                # "Status: queued..." and "Status: running..." are not final
                if not status.endswith("..."):
                    break
            print(status)


asyncio.run(main())
```

The `qwed-mcp` repository ships a fuller version of this client in its `examples` directory.

### Math, logic and SQL engines

The math, logic and SQL engines in `qwed_mcp.engines` are a Python library API, not MCP tools, and `execute_python_code` scripts can't import them. Call them from your own code, for example:

```python
from qwed_mcp.engines.sql_engine import verify_sql_query

result = verify_sql_query("SELECT * FROM users WHERE id = '1' OR '1'='1'")
print(result["verified"])  # False: the condition does not depend on the row
```

## Best practices

### 1. Always verify before responding

```text
User asks → AI calculates → AI writes verification script → AI responds
                             ↓ (if fails)
                         AI recalculates
```

### 2. Use background mode for heavy tasks

Set `background=true` when running scripts that may take longer than 30 seconds. Poll results using `verification_status` with the returned `job_id`.

### 3. Use admitted modules

| Task | Admitted modules |
| --- | --- |
| Money and exact decimals | `decimal` |
| Exact fractions | `fractions` |
| Math functions | `math`, `cmath` |
| Statistics | `statistics` |
| Propositional logic over truth assignments | `itertools` (`product`) |
| Dates | `datetime`, `calendar` |

See [What code is admitted](/mcp/tools#what-code-is-admitted) for the full rules.

### 4. Handle verification failures

When verification fails:

1. Acknowledge the error
2. Recalculate
3. Verify again
4. Explain the correction to user

### 5. Explain verification to users

```text
"I calculated X. Let me verify this is correct...
[Runs verification script]
✅ Verified using deterministic computation.
The answer is definitely X."
```
