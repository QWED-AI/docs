**Model Context Protocol (MCP) Server for QWED Verification**

![PyPI version](https://img.shields.io/pypi/v/qwed-mcp)
 ![Tests](https://github.com/QWED-AI/qwed-mcp/actions/workflows/publish.yml/badge.svg)
 ![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)

QWED-MCP brings deterministic computation to Claude Desktop, VS Code, and any MCP-compatible AI assistant. Instead of trusting LLMs to compute correctly, QWED-MCP runs Python scripts written by the assistant. From v0.3.0, a script runs only when every module, builtin and attribute it uses is on an allowlist of computation-only standard-library features. All execution is local.

Use QWED-MCP when you want an MCP-compatible assistant to check a calculation or an argument with a script instead of computing the answer itself.

<Warning>
  `execute_python_code` runs admitted code in a subprocess **with the server's privileges**. It is not a sandbox. The subprocess gets a restricted set of environment variables, and calls pass through the `RiskBasedExecutionGateway`, but only enable code execution where you trust the inputs.
</Warning>

---

## Why QWED-MCP?

### The problem

LLMs are unreliable for:

- **Mathematical calculations** - They approximate, don't compute
- **Logical reasoning** - They guess patterns, don't prove
- **Code security** - They miss edge cases, don't analyze
- **SQL queries** - They don't validate, just generate

### The solution

QWED-MCP gives AI assistants a single `execute_python_code` tool. The LLM writes a Python script, the server admits it only if it stays within the [allowlist](/mcp/tools#what-code-is-admitted), and then runs it in a subprocess with restricted environment variables and the server's privileges.

| Without QWED-MCP | With QWED-MCP |
| --- | --- |
| LLM-only math → approximated by the model | Script computes with `decimal` or `fractions` → exact arithmetic |
| LLM-only reasoning → unchecked | Script checks a propositional argument over every truth assignment with `itertools.product` |
| LLM-only statistics → approximated | Script computes with the `statistics` module |

From v0.3.0, scripts can't import third-party packages, so SymPy, Z3 and the QWED SDK packages are not available to them. Executing a script is not itself verification: what a run checks depends entirely on the script the assistant wrote, so review it. See [qwedai.tech/limits](https://qwedai.tech/limits).

## How it works

```text
┌─────────────────────────────────────────────────────────────┐
│                    Your AI Application                       │
│  ┌─────────────────┐        ┌─────────────────────────────┐ │
│  │  Claude Desktop │        │        VS Code + Copilot    │ │
│  │  or any MCP     │        │        or any MCP Client    │ │
│  │  compatible     │        │                             │ │
│  └────────┬────────┘        └──────────────┬──────────────┘ │
└───────────┼─────────────────────────────────┼───────────────┘
            │                                 │
            │         MCP Protocol            │
            │       (JSON-RPC over stdio)     │
            ▼                                 ▼
┌──────────────────────────────────────────────────────────────┐
│                     QWED-MCP Server (v0.3.0)                 │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ┌────────────────────────────────────────────────────────┐  │
│  │          RiskBasedExecutionGateway                     │  │
│  │  └─► Policy lookup → Argument validation →            │  │
│  │      Allowlist admission → Admin policy enforcement   │  │
│  ├────────────────────────────────────────────────────────┤  │
│  │              execute_python_code                       │  │
│  │  ├─► Synchronous Execution (30s timeout)               │  │
│  │  └─► Background Execution (background=true)            │  │
│  │       └─► Async Job Queue (up to 5 concurrent)         │  │
│  │           └─► python -I subprocess                     │  │
│  │               └── admitted standard-library modules    │  │
│  │                   (math, decimal, fractions, ...)      │  │
│  ├────────────────────────────────────────────────────────┤  │
│  │              verification_status                       │  │
│  │  └─► Poll background job results by job_id             │  │
│  └────────────────────────────────────────────────────────┘  │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## Available tools

| Tool | Description | Use case |
| --- | --- | --- |
| [`execute_python_code`](/mcp/tools#execute_python_code) | Subprocess execution | Runs dynamically generated Python code after the [allowlist admission check](/mcp/tools#what-code-is-admitted). Supports optional `background=true` for async execution. |
| [`verification_status`](/mcp/tools#verification_status) | Job status polling | Check the status and results of background verification jobs dispatched via `execute_python_code` with `background=true`. |

All tool calls pass through the [`RiskBasedExecutionGateway`](/mcp/tools#riskbasedexecutiongateway-governance) before dispatch. The gateway validates arguments, runs the allowlist admission check, and enforces admin policy. The gateway blocks unknown tools by default.

<Info>
  In v0.1.x, QWED-MCP exposed individual tools like `verify_math`, `verify_logic`, `verify_code`, and `verify_sql`. These were consolidated into `execute_python_code` in v0.2.0 to solve context bloat (RFC-9728 compatibility). See [migration guide](/mcp/tools#migrating-from-v0-1-x).
</Info>

## Installation

### From PyPI (recommended)

```bash
pip install qwed-mcp
```

qwed-mcp 0.2.3 and later require Python 3.10 or later and the MCP Python SDK `mcp>=1.30.0,<2`. MCP SDK 2.x removed the server API that qwed-mcp uses, so pip keeps the SDK on 1.x.

From v0.3.0, qwed-mcp no longer installs `qwed-finance` or `qwed-ucp`, and no longer declares `httpx` directly (`mcp` still installs it). If your own code imports any of them, add them to your own project's dependencies.

### From source

```bash
git clone https://github.com/QWED-AI/qwed-mcp.git
cd qwed-mcp
pip install -e .
```

### Verify installation

```bash
pip show qwed-mcp
# Name: qwed-mcp
# Version: 0.3.0
```

The `qwed-mcp` command starts the server over stdio and has no `--version` flag.

## Quick start

### Claude Desktop setup

1. **Find your config file:**
   - **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
   - **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
   - **Linux:** `~/.config/Claude/claude_desktop_config.json`
2. **Add QWED-MCP server:**

```json
{
  "mcpServers": {
    "qwed-verification": {
      "command": "qwed-mcp",
      "env": {
        "QWED_MCP_TRUSTED_CODE_EXECUTION": "true"
      }
    }
  }
}
```

3. **Restart Claude Desktop**
4. **Test it!** Ask Claude:
   > "Write a Python script that verifies a $10,000 investment at 7.5% for 5 years using the compound interest formula, and run it using execute\_python\_code."

### VS Code setup

1. **Install MCP extension** (if not already)
2. **Add to settings.json:**

```json
{
  "mcp.servers": {
    "qwed-verification": {
      "command": "qwed-mcp",
      "env": {
        "QWED_MCP_TRUSTED_CODE_EXECUTION": "true"
      }
    }
  }
}
```

3. **Restart VS Code**

### Python client

You can also use QWED-MCP programmatically:

```python
import asyncio
from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client

async def main():
    server_params = StdioServerParameters(
        command="qwed-mcp",
        env={"QWED_MCP_TRUSTED_CODE_EXECUTION": "true"}
    )
    
    async with stdio_client(server_params) as (read, write):
        async with ClientSession(read, write) as session:
            await session.initialize()
            
            # List available tools
            tools = await session.list_tools()
            print(f"Available tools: {[t.name for t in tools.tools]}")
            # Output: Available tools: ['execute_python_code', 'verification_status']
            
            # Run a verification script
            result = await session.call_tool(
                "execute_python_code",
                arguments={
                    "code": (
                        "from fractions import Fraction\n"
                        "print(Fraction(1, 3) + Fraction(1, 6))"
                    )
                }
            )
            print(result)

asyncio.run(main())
```

## Configuration

### Environment variables

| Variable | Description | Default |
| --- | --- | --- |
| `QWED_MCP_TRUSTED_CODE_EXECUTION` | Enable `execute_python_code` tool (`true`/`false`) | `false` |
| `QWED_LOG_LEVEL` | Logging level (`DEBUG`, `INFO`, `WARNING`, `ERROR`) | `INFO` |
| `QWED_TIMEOUT` | Synchronous tool execution timeout in seconds | `30` |
| `QWED_MCP_BACKGROUND_TIMEOUT` | Background worker timeout in seconds for jobs dispatched with `background=true`. Clamped to a hard ceiling of `600`. Non-numeric or non-positive values fall back to the default | `120` |
| `QWED_SKILL_MANIFEST` | Path to a skill manifest JSON file. When set, the server validates the manifest at startup using [`SkillProvenanceGuard`](/mcp/tools#skillprovenanceguard-security) and refuses to start if verification fails | Not set |

<Warning>
  Set `QWED_MCP_TRUSTED_CODE_EXECUTION` to `true` to enable code execution. The executed code runs with server privileges — ensure inputs are from trusted sources.
</Warning>

### Example with environment variables

**Windows (PowerShell):**

```powershell
$env:QWED_MCP_TRUSTED_CODE_EXECUTION = "true"
$env:QWED_LOG_LEVEL = "DEBUG"
qwed-mcp
```

**macOS/Linux:**

```bash
QWED_MCP_TRUSTED_CODE_EXECUTION=true QWED_LOG_LEVEL=DEBUG qwed-mcp
```

## Use cases

### 1. Financial calculations

Verify that AI-generated financial calculations are correct:

```text
User: Calculate compound interest for $10,000 at 5% for 3 years

Claude: Let me verify this calculation.
        [Calls execute_python_code with a script using Decimal math]
        
        STDOUT: Future value = $11576.25
        ✅ Verified using deterministic decimal arithmetic.
```

### 2. Research validation

Check that a conclusion follows from its premises:

```text
User: If all mammals are warm-blooded, and dolphins are mammals,
      are dolphins warm-blooded?

Claude: [Calls execute_python_code with a script that checks every
         true/false assignment with itertools.product]

        STDOUT: valid: True
```

### 3. Refused code

Code that reaches outside the allowlist is refused before it runs:

```text
User: Run this: import os; print(os.listdir("."))

Claude: [Calls execute_python_code]

        BLOCKED: QWED blocked python execution: Module 'os' is not
        admitted (line 1) (verification_id=...)
```
