## Example 1: financial calculator agent

### Scenario

An AI agent helps users with financial calculations. Need to verify math before returning results.

### Setup

```python
from qwed_open_responses import ResponseVerifier
from qwed_open_responses.guards import MathGuard, SchemaGuard

verifier = ResponseVerifier()

# Schema for invoice calculations
invoice_schema = {
    "type": "object",
    "required": ["subtotal", "tax", "total"],
    "properties": {
        "subtotal": {"type": "number", "minimum": 0},
        "tax": {"type": "number", "minimum": 0},
        "discount": {"type": "number", "minimum": 0},
        "total": {"type": "number"}
    }
}

math_guard = MathGuard()
schema_guard = SchemaGuard(schema=invoice_schema)
```

MathGuard checks `total = subtotal + tax + shipping - discount`, counting any missing part as zero. See [what it checks](/open-responses/guards#what-it-checks) for the other shapes.

### Verification

```python
# Agent output: $200 subtotal, $16 tax, $20 discount, $196 total
agent_output = {
    "subtotal": 200,
    "tax": 16,
    "discount": 20,
    "total": 196
}

result = verifier.verify_structured_output(
    output=agent_output,
    guards=[schema_guard, math_guard]
)
print(result.verified)
# True
```

### Catching errors

```python
# Agent makes a mistake: forgets to subtract the discount
bad_output = {
    "subtotal": 200,
    "tax": 16,
    "discount": 20,
    "total": 216  # Wrong!
}

result = verifier.verify_structured_output(
    output=bad_output,
    guards=[schema_guard, math_guard]
)
print(result.verified, result.block_reason)
# False Math verification failed: 1 error(s)
print(result.guard_results[1].details["errors"])
# ['total mismatch: expected 216.0, calculated 196.0']
```

## Example 2: blocking dangerous tools

### Scenario

Agent has access to shell commands. Need to prevent dangerous operations.

### Setup

```python
from qwed_open_responses import ResponseVerifier
from qwed_open_responses.guards import ToolGuard

verifier = ResponseVerifier()

# Create blocklist (added to the default blocklist)
tool_guard = ToolGuard(
    blocked_tools=[
        "execute_shell",
        "delete_file",
        "drop_table",
        "send_email",
        "transfer_funds"
    ],
    dangerous_patterns=[
        r"rm\s+-rf",
        r"DROP\s+TABLE",
        r"DELETE\s+FROM.*WHERE\s+1=1"
    ]
)
```

### Blocked calls

```python
# Agent tries to call dangerous tool
result = verifier.verify_tool_call(
    tool_name="execute_shell",
    arguments={"command": "rm -rf /"},
    guards=[tool_guard]
)
print(result.verified, result.block_reason)
# False BLOCKED: Tool 'execute_shell' is not allowed

# Agent passes a dangerous argument to a tool that is not blocked
result = verifier.verify_tool_call(
    tool_name="run_query",
    arguments={"sql": "DELETE FROM users WHERE 1=1"},
    guards=[tool_guard]
)
print(result.verified, result.block_reason)
# False BLOCKED: Dangerous pattern detected in tool arguments
```

### Allowed calls

```python
# Safe tool call
result = verifier.verify_tool_call(
    tool_name="read_file",
    arguments={"path": "/data/report.txt"},
    guards=[tool_guard]
)
print(result.verified)
# True
```

## Example 3: PII detection

### Scenario

Healthcare AI generating patient summaries. Must not leak PII.

### Setup

```python
from qwed_open_responses import ResponseVerifier
from qwed_open_responses.guards import SafetyGuard

safety_guard = SafetyGuard(
    check_pii=True,  # SSN, credit card, phone, email, IP address
    custom_patterns=[
        r"\b[A-Z]{2}\d{6}\b",  # Passport
    ]
)

# PII findings are warnings. allow_warnings=False makes them block.
verifier = ResponseVerifier(allow_warnings=False)
```

### PII blocked

```python
# Agent generates summary with SSN
summary = """
Patient John Doe (SSN: 123-45-6789) presented with...
"""

result = verifier.verify({
    "content": summary
}, guards=[safety_guard])
print(result.verified, result.block_reason)
# False Safety warnings: 1 warning(s)
print(result.guard_results[0].details["issues"])
# [{'type': 'pii', 'severity': 'warning', 'details': ['ssn']}]
```

A match on a `custom_patterns` entry is an error rather than a warning, so it blocks with any verifier:

```python
result = ResponseVerifier().verify({
    "content": "Passport AB123456 on file"
}, guards=[safety_guard])
print(result.verified, result.block_reason)
# False Safety check failed: 1 critical issue(s)
```

### Warn instead of block

```python
# With the default allow_warnings=True, PII passes as a warning you can log
result = ResponseVerifier().verify({"content": summary}, guards=[safety_guard])
print(result.verified)
# True
print([warning.message for warning in result.warnings])
# ['Safety warnings: 1 warning(s)']
```

SafetyGuard detects PII but does not redact it. Redact in your own code before you return the text.

## Example 4: state machine validation

### Scenario

Order processing agent. States must follow valid transitions.

### Setup

```python
from qwed_open_responses import ResponseVerifier
from qwed_open_responses.guards import StateGuard

verifier = ResponseVerifier()

# Define valid transitions
state_guard = StateGuard(
    transitions={
        "pending": ["processing", "cancelled"],
        "processing": ["shipped", "failed"],
        "shipped": ["delivered", "returned"],
        "delivered": ["completed"],
        "failed": ["pending"],  # Can retry
        "cancelled": [],  # Terminal state
        "completed": [],  # Terminal state
    }
)
```

StateGuard reads the requested state from `new_state` in the output. It does not read tool-call arguments, so pass the transition as structured output. Take the current state from your own records and pass it as `context["current_state"]`. That value wins over any `state` field in the output, so the agent can't claim a different starting state to make a transition pass.

### Valid transition

```python
result = verifier.verify_structured_output(
    output={
        "order_id": "ORD-123",
        "new_state": "shipped"
    },
    guards=[state_guard],
    context={"current_state": "processing"}  # From your order database
)
print(result.verified)
# True
```

### Invalid transition (blocked)

```python
result = verifier.verify_structured_output(
    output={
        "order_id": "ORD-123",
        "state": "failed",  # Agent claims a state that could move to pending
        "new_state": "pending"  # Can't go back!
    },
    guards=[state_guard],
    context={"current_state": "delivered"}  # From your order database
)
print(result.verified, result.block_reason)
# False Invalid transition: 'delivered' -> 'pending'
print(result.guard_results[0].details["valid_next_states"])
# ['completed']
```

## Example 5: LangChain integration

### Full agent with verification

```python
from langchain_openai import ChatOpenAI
from langchain.agents import create_agent
from langchain.tools import tool
from qwed_open_responses.middleware.langchain import QWEDCallbackHandler
from qwed_open_responses.guards import ToolGuard, SafetyGuard

# Define tools
@tool
def multiply(a: float, b: float) -> str:
    """Multiply two numbers."""
    return str(a * b)

@tool
def send_email(to: str, subject: str, body: str) -> str:
    """Send an email."""
    return f"Email sent to {to}"

# Create verification callback
callback = QWEDCallbackHandler(
    guards=[
        ToolGuard(blocked_tools=["send_email"]),  # Block email for now
        SafetyGuard(),
    ],
    block_on_failure=True,
    verbose=True
)

# Create agent
llm = ChatOpenAI(model="gpt-4")
agent = create_agent(llm, tools=[multiply, send_email])

# Run agent, passing the callback in config
result = agent.invoke(
    {"messages": [{"role": "user", "content": "Calculate 15% tip on $85.50"}]},
    config={"callbacks": [callback]}
)

# Output:
# [QWED] Tool start: multiply -> [OK] Verified (2 guards passed)
```

MathGuard is not in this callback. It checks a response's `output`, not tool-call arguments, so it would block every tool call with "No verifiable math found in response". See the [LangChain integration](/open-responses/langchain) for how the callback sees each tool call.

## Example 6: budget control

### Scenario

Prevent runaway API costs from agent loops.

### Setup

```python
from qwed_open_responses import ResponseVerifier
from qwed_open_responses.guards import SafetyGuard

verifier = ResponseVerifier()

# Per-session budget
safety_guard = SafetyGuard(max_cost=10.0)  # $10 per session
```

SafetyGuard does not price calls. Keep your own running cost for the session and pass it as `context["total_cost"]` on each check. Any `usage.cost` the response reports is added to that total. With no cost figure at all, the budget check fails closed.

### Budget enforcement

```python
# After many calls, your running total is $10.24
result = verifier.verify_tool_call(
    tool_name="generate_image",
    arguments={"prompt": "A cat"},
    guards=[safety_guard],
    context={"total_cost": 10.24}
)
print(result.verified, result.block_reason)
# False Safety check failed: 1 critical issue(s)
print(result.guard_results[0].details["issues"][0]["details"])
# ['Cost exceeds limit: $10.24 > $10.0']
```

## Example 7: argument type validation

### Scenario

Ensure tool arguments match expected types.

### Setup

```python
from qwed_open_responses import ResponseVerifier
from qwed_open_responses.guards import ArgumentGuard

verifier = ResponseVerifier()

# Define expected argument types per tool
arg_guard = ArgumentGuard(
    tool_rules={
        "transfer_money": {
            "from_account": {"type": "pattern", "pattern": r"^ACC-\d{8}$", "required": True},
            "to_account": {"type": "pattern", "pattern": r"^ACC-\d{8}$", "required": True},
            "amount": {"type": "number", "min": 0.01, "max": 10000, "required": True},
            "currency": {"type": "enum", "values": ["USD", "EUR", "GBP"]}
        }
    }
)
```

### Validation

```python
# Invalid amount
result = verifier.verify_tool_call(
    tool_name="transfer_money",
    arguments={
        "from_account": "ACC-12345678",
        "to_account": "ACC-87654321",
        "amount": "one hundred",  # Should be number!
        "currency": "USD"
    },
    guards=[arg_guard]
)
print(result.verified, result.block_reason)
# False Argument validation failed: 1 error(s)
print(result.guard_results[0].details["errors"])
# ['amount: expected number, got str']
```

## Best practices

### 1. Layer multiple guards

```python
from qwed_open_responses import (
    ResponseVerifier,
    ArgumentGuard,
    MathGuard,
    SafetyGuard,
    SchemaGuard,
    ToolGuard,
)

# Layered checks for tool calls
tool_verifier = ResponseVerifier(default_guards=[
    ToolGuard(allowed_tools=["search", "get_weather"]),  # Tool allowed?
    ArgumentGuard(tool_rules={                           # Args valid?
        "get_weather": {"city": {"type": "string", "required": True}},
    }),
    SafetyGuard(),                                       # Safe content?
])

# Layered checks for structured outputs
output_verifier = ResponseVerifier(default_guards=[
    SchemaGuard(schema=invoice_schema),  # Structure valid? (schema from Example 1)
    MathGuard(),                         # Math correct?
])
```

Keep `SchemaGuard` and `MathGuard` in a separate stack from tool-call checks. A tool call does not match your output schema and carries no math, so both would fail it.

### 2. Fail fast, log everything

```python
import logging
from qwed_open_responses import SafetyGuard, ToolGuard
from qwed_open_responses.middleware.langchain import QWEDCallbackHandler, ToolCallBlocked

logger = logging.getLogger(__name__)

callback = QWEDCallbackHandler(
    guards=[ToolGuard(), SafetyGuard()],
    block_on_failure=True,
    verbose=True
)

try:
    agent.invoke(inputs, config={"callbacks": [callback]})
except ToolCallBlocked as e:
    logger.error("Blocked: %s", e.result.block_reason)
    raise
```

### 3. Environment-specific guards

```python
import os
from qwed_open_responses import SafetyGuard, ToolGuard

if os.getenv("ENV") == "production":
    guards = [ToolGuard(allowed_tools=PROD_TOOLS), SafetyGuard()]
else:
    guards = [ToolGuard()]  # Default blocklist only, more lenient in dev
```

### 4. Test your guards

```python
from qwed_open_responses import ToolGuard

def test_tool_guard_blocks_dangerous():
    guard = ToolGuard(blocked_tools=["delete_all"])
    result = guard.check({"type": "tool_call", "tool_name": "delete_all", "arguments": {}})
    assert not result.passed
    assert "not allowed" in result.message
```
