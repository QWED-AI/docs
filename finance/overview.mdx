<Note>
The QWED Finance documentation now lives on its own site: **[finance.qwedai.com](https://finance.qwedai.com)**. Links to the old `/finance/...` pages on this site redirect there automatically.
</Note>

**QWED Finance** verifies what financial AI agents produce before your system acts on it. NPV and IRR claims, AML and KYC decisions, ISO 20022 and SWIFT messages, SQL queries, bond, FX, and risk metrics, and trading orders are recomputed or checked deterministically, and inputs that cannot be checked fail closed.

The current release is **v3.0.1** (`pip install qwed-finance`, `npm install @qwed-ai/finance`).
