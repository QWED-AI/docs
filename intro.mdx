## What is QWED?

QWED (Query With Evidence & Determinism) is a trust boundary for AI systems:

- LLMs can translate user intent into structured claims.
- QWED verifies those claims with deterministic engines before execution or response.
- You get proof-backed outcomes instead of probability-only confidence.

QWED is designed for LLM verification, AI agent security, verified tool calls, prompt injection defense, and deterministic transaction verification in high-stakes workflows.

> **"Do not trust generated output. Verify it."**

```mermaid

    U[User Query] --> L[LLM Translation]
    L --> Q[QWED Verification]
    Q --> R[Verified Result]

    L -. Untrusted output .-> X[Possible hallucination]

    class R result;
```

## Quick start (5 minutes)

```bash
pip install qwed==9.1.0
```

The examples below use the `qwed` CLI that this installs. The `qwedai/qwed-verification:9.1.0` Docker image runs the API server instead; see [Self-hosting](/advanced/self-hosting#docker).

```bash
# Run every engine on known cases (no LLM needed)
qwed test
# Math:
#   [ok] 2+2=4                  -> VERIFIED | ADMIT
#   [ok] 2+2=5                  -> VERIFIED (false) | DENY
#   ...

# Verify logic constraints
qwed verify-logic "(AND (GT x 5) (LT y 10))"
# -> SAT: {x=6, y=9}
```

## What's new in v9

<AccordionGroup>
  <Accordion title="Allowlist admission for Python code" icon="shield-check" defaultOpen>
    From v9.1.0, `CodeVerifier` admits Python code only when every module, module name, builtin and special attribute it uses is on a list, and the code reads no attribute by a name made at run time. Each refusal names the module, builtin or attribute. A caller can name modules its own runtime confines with `trusted_modules`, as the code-execution sandbox does for `numpy` and `pandas`; the module checks then skip those modules, so they need that confinement. [Read the 9.1.0 notes →](/changelog#v9-1-0-—-allowlist-admission-for-python-code)
  </Accordion>
  <Accordion title="Before you upgrade" icon="triangle-exclamation">
    From v9.0.0, QWED names no model of its own: set your provider's model variable, such as `OPENAI_MODEL` or `ANTHROPIC_MODEL`, and pass `model=` to `QWEDLocal`, `verify()` and `qwed_sdk.integrations.langchain.QWEDTool`. `/verify/math` runs in worker processes with a time limit, the CSV exports change their columns, and the Go module path moves to `/v9`. Upgrade every server process together. [Read the upgrade steps →](/changelog#v9-0-0-—-eleven-advisories-and-models-you-configure)
  </Accordion>
</AccordionGroup>
